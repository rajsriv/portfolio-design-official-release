## Quick start

To preview locally:

1. Clone the repository
   ```
   git clone https://github.com/rajsriv/portfolio-design-official-release.git
   cd portfolio-design-official-release
   ```
2. Open the site in your browser:
   - Open `index.html` directly, or
   - Serve locally with a static server (optional)
     ```
     npx http-server -c-1 .   # or use any static server
     ```
3. Visit `http://localhost:8080` (or the port your server prints).

## Development

- Edit HTML files in the root or the `public` (if present) folder.
- Modify styles in the CSS files (main stylesheet(s) located in the repository).
- Update interactive behaviour in JavaScript files.

If the project uses a build step or npm scripts, add a `package.json` with appropriate commands (not required for a plain static site).

## Deployment

The site is already deployed at the Vercel URL above. To redeploy or connect the repository to Vercel:

1. Log in to [Vercel](https://vercel.com).
2. Import the GitHub repository.
3. Configure the build/deploy settings (for static sites no build command may be necessary).
4. Deploy — Vercel will provide a production URL.
